# ROMs and disk images

Everything in this directory except this file is ignored by git. The
repository ships no copyrighted software, so you supply these files yourself.

What goes here:

| File                                                       | Used for                                                    |
|------------------------------------------------------------|-------------------------------------------------------------|
| `TST8080.COM`, `8080PRE.COM`, `CPUTEST.COM`, `8080EXM.COM` | CPU diagnostics, run by `crates/i8080/tests/diagnostics.rs` |

You can download the diagnostics from the
[`cpu_tests`](https://github.com/superzazu/8080/tree/master/cpu_tests)
folder of the superzazu/8080 emulator.
