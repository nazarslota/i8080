# C programs for CP/M

C programs that run under CP/M on the emulated Altair.
`make run PROGRAM=name` compiles `name.c` with z88dk and runs it;
[docs/guide/cpm.md](../../docs/guide/cpm.md#c-programs) explains the
steps.

| File     | What it does                               |
|----------|--------------------------------------------|
| `main.c` | an empty program to start from: `make run` |
